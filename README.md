CubeShade: a studio catalogue photograph of an impossible gadget — the world's smallest beach umbrella, engineered to shade exactly one ice cube in a drinking glass, shot with one tiny deckchair. `render.py` (Python PIL) draws the 1024×1024 PNG from scratch; `main.ts` copies it to `/output/entry.png`.

## Run it

```sh
python3 render.py && node main.ts
```
